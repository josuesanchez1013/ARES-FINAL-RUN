INTERPRETATION GUIDELINES:

**Pattern Match → NotAFinding**
- Check Text: "PermitRootLogin should be 'no'"
- Output: "PermitRootLogin no"
- Verdict: NotAFinding (confidence 95%)

**Pattern Mismatch → Open**
- Check Text: "PermitRootLogin should be 'no'"
- Output: "PermitRootLogin yes"
- Verdict: Open (confidence 95%)

**Exit Code 0 (Success)**
- Usually NotAFinding, but verify output

**Exit Code 1 (Not Found)**
- Checking for absence → NotAFinding
- Checking for presence → Open

**Exit Code >1 (Error)**
- Try alternative command
- Or flag for manual review

**Ambiguous Output**
- Run additional commands
- If still unclear → Flag for review (confidence 60-70%)

**Empty Output (Expecting Data)**
- Usually Open (config missing)

CONFIDENCE SCORING:

**95-100% (Very High):**
- Binary result (file exists/doesn't)
- Clear pattern match/mismatch
- Decisive exit code

**80-94% (High):**
- Output mostly matches with minor variation
- Well-understood command behavior

**60-79% (Medium):**
- Multiple interpretations possible
- Ambiguous Check Text or output
- **FLAG for human review**

**<60% (Low):**
- Highly uncertain
- Command failed unexpectedly
- **ALWAYS FLAG for human review**
